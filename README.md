# Prank App

A single-page mobile-style prank app. It opens on a dashboard showing a ₦750,000.00 balance. Tapping **Make Transfer** (or the Transfer tab) shows a black popup with red text: "This account is restricted."

For fun only. Do not use it to deceive anyone into thinking the balance is real.

## Run
Open `index.html` in a browser (best on a phone-sized screen).

## Host on GitHub Pages
1. Push `index.html` to a repo.
2. Settings → Pages → deploy from the `main` branch, root folder.

## Use offline on Android
**Quickest:** download `index.html` to your phone, open it from the Files app with Chrome. It needs no internet.

**As an installable app:** host the folder on GitHub Pages, open the link once in Chrome, then menu → Add to Home screen / Install app. After that it works offline from your home screen.
